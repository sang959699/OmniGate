iOS Shortcuts Integration Assistant

POST Method

Below are the custom webhook URLs for your devices. Click any URL to copy it, then paste it into your iOS Shortcuts app's "Get Contents of URL" action (set to POST).

Device / Outlet ON / Run URL Trigger OFF URL Toggle State URL

iOS Shortcut Setup Guide:

  1. Open the Shortcuts app on iOS and create a new Shortcut.
  2. Search for and add the Get Contents of URL action.
  3. Copy one of the green URLs above and paste it into the URL field. Use OmniGate's LAN IP address (for example 192.168.1.10:5000) instead of localhost so the iPhone can reach the server.
  4. Expand the action detail and set the Method to POST.
  5. Save and trigger the shortcut by saying "Hey Siri, [Shortcut Name]"!
